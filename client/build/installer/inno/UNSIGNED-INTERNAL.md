# 内网分发安装说明（unsigned 安装包）

本安装包**未做代码签名**，仅用于内网分发。Windows 首次运行会弹出 SmartScreen 提示，按下面步骤继续安装。

## 1. 文件命名

- 安装包：`数据集团工具箱-Setup-<版本>-unsigned.exe`
- 文件名中的 **-unsigned** 表示未签名，请勿与正式签名包混淆。

## 2. Windows SmartScreen 提示处理

| 步骤 | 界面 | 操作 |
|---|---|---|
| 1 | “Windows 已保护你的电脑” | 点击左侧 **更多信息** |
| 2 | 展开后出现应用名与发布者“未知” | 点击右下角 **仍要运行** |
| 3 | 安装向导 | 按向导完成安装 |

截图位置：`docs/images/smartscreen-run-anyway.png`（**待补**：需在真实内网机首次运行时截取，本仓库当前未附截图，避免使用非真实截图）

## 3. 组策略/杀软拦截

- 若被组策略拦截（如“已阻止此应用”），需内网管理员把该安装包加入白名单或软件分发白名单；
- 若杀软误报，提交误报样本到内网杀软控制台，或按公司流程加白。

## 4. 校验（可选）

```powershell
Get-FileHash .\数据集团工具箱-Setup-<版本>-unsigned.exe -Algorithm SHA256
```

## 5. 卸载

控制面板 → 应用 → 数据集团工具箱 → 卸载；或运行安装目录下的 `unins000.exe`。

## 6. 正式发布前置

正式对外分发前必须取得代码签名证书并在 setup.iss 启用 `SignTool`，同时恢复不带 `-unsigned` 的产物命名。
